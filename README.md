# Arabic Orbit — الموقع مع لوحة التحكم

عندك **طريقتان** لتعديل الموقع، وتعطيان النتيجة نفسها:

1. **لوحة التحكم** (Pages CMS): نماذج وأزرار، من أي جهاز حتى الهاتف.
2. **يدويًا**: تعدّل ملفات المجلد `content/` في VS Code أو مباشرة على موقع GitHub.

في الحالتين: بعد الحفظ، يبني GitHub الموقع وينشره **تلقائيًا** خلال دقيقتين تقريبًا.

---

## محتوى المجلد

| المسار | ما فيه | من يعدّله |
|---|---|---|
| `content/stories.json` | قصص جحا: النص العربي، الصورة، الترجمات، العبرة | أنت (لوحة التحكم أو يدويًا) |
| `content/videos.json` | فيديوهات يوتيوب لكل لغة | أنت |
| `content/books.json` | نسخ الكتاب: روابط الشراء والعيّنات ونصوص الأزرار | أنت |
| `content/settings.json` | السعر، روابط فيسبوك ويوتيوب وبنتريست والمتجر | أنت |
| `content/seo.json` | عنوان ووصف كل لغة في Google | أنت |
| `public/img/` | صور القصص | أنت (ترفعها من لوحة التحكم) |
| `src/template.html` | التصميم والنصوص الثابتة للواجهة | للتعديلات المتقدمة فقط |
| `build.js` و `.github/` و `.pages.yml` | البناء والنشر وإعداد لوحة التحكم | لا تعدّلها |

## الإعداد (مرة واحدة)

### 1) رفع المجلد إلى GitHub
1. أنشئ حسابًا مجانيًا على **github.com**.
2. افتح هذا المجلد في **VS Code** (File ← Open Folder).
3. من الشريط الجانبي اضغط أيقونة **Source Control** ثم **Publish to GitHub**، وسجّل الدخول، واختر **Public repository** (أو Private إن كان حسابك يسمح بـ GitHub Pages الخاص).

### 2) تشغيل النشر التلقائي (GitHub Pages)
1. في صفحة المستودع على GitHub: **Settings ← Pages**.
2. في **Source** اختر **GitHub Actions**.
3. اذهب إلى تبويب **Actions**: ستجد عملية «Build and publish the site». بعد أن تصبح خضراء ✔ يكون الموقع منشورًا.

### 3) ربط النطاق arabicorbit.com
1. في GitHub: **Settings ← Pages ← Custom domain** اكتب `arabicorbit.com` واحفظ.
2. في **Cloudflare ← arabicorbit.com ← DNS** أضف السجلات التي يطلبها GitHub (صفحة الإعداد تعرضها لك).
3. فعّل **Enforce HTTPS** في GitHub بعد أن يتحقق من النطاق.

### 4) تفعيل لوحة التحكم
1. افتح **app.pagescms.org** واضغط **Sign in with GitHub**.
2. اسمح له بالوصول إلى مستودع الموقع.
3. اختر المستودع: تظهر لك الأقسام بالعربية: **قصص جحا، فيديوهات يوتيوب، الكتب، إعدادات عامة، السيو**.

## الاستعمال اليومي من لوحة التحكم

- **إضافة قصة:** قصص جحا ← **Add an entry** ← املأ العنوان والنص (كل جملة في سطر) وارفع الصورة واكتب الترجمات ← **Save**.
  - إن تركت ترجمة لغة فارغة، تظهر الترجمة الإنجليزية مكانها.
- **إضافة فيديو:** فيديوهات يوتيوب ← اختر اللغة ← **Add** ← الصق الرابط والعنوان ← **Save**.
  - اللغة التي ليس لها أي فيديو تظهر فيها رسالة «قريبًا».
- **تغيير السعر أو الروابط:** إعدادات عامة ← **Save**.

## التعديل اليدوي (بدل لوحة التحكم)

افتح ملفات `content/*.json` في VS Code، عدّل، ثم في Source Control: اكتب وصفًا واضغط **Commit** ثم **Sync**. الباقي تلقائي.

انتبه في ملفات JSON إلى علامات التنصيص `"` والفواصل `,` بين العناصر. إن أخطأت، تفشل عملية النشر في تبويب **Actions** وتظهر رسالة تحدد الملف، ويبقى الموقع القديم منشورًا حتى تصحح الخطأ.

## معاينة الموقع على حاسوبك (اختياري)

يتطلب **Node.js** (نسخة LTS):
```
npm install
npm run setup
npm run build
```
ثم افتح `dist/index.html` بإضافة **Live Server**.

## نصائح للصور

- عمودية بنسبة **3:4** (مثلًا 720×960).
- يفضَّل **webp أو jpg** بحجم أقل من **300 كيلوبايت** حتى يبقى الموقع سريعًا.
